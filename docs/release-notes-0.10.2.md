# Fast Page Chat 0.10.2 — GitHubベータ版

Chrome 154で、ツールバーの拡張機能ボタンからパネルを開いてもページ本文を取得できない問題に対応しました。サイドパネルの自動開閉に任せていた処理を、通常の拡張機能ボタン操作へ変更しています。ボタンを押したページへの一時的な権限を使い、全サイトへの権限は追加しません。本文・画像・会話の送信先と保存先は0.10.1と同じです。

Codexの既定モデルでは回答が成功しても、自動タイトルだけ「モデルIDが不正です」と失敗する問題も修正しました。会話と同じ既定モデルをタイトルにも使用します。

単体テスト86件とWindows補助アプリの回帰14項目が成功しました。Windows 11 HomeのVMで本文取得、Codexの実回答、タイトルの再生成、履歴を保った更新とChrome再起動後の再接続を確認しています。API・画像の実送信などは未確認です。確認範囲と残る項目は[0.10.2の検証記録](https://github.com/Ringoacid/fast-page-chat/blob/main/docs/validation-0.10.2.md)を参照してください。

## 操作の変更

拡張機能ボタンは、現在のページを読むためにパネルを開く操作になります。もう一度押してもパネルは閉じず、新しい会話の準備中なら本文を再取得します。保存済みの会話は開始時のページを維持し、生成中の処理は中断しません。パネルを閉じるには右上の「×」を押してください。

初回案内の確認と接続設定は引き続き必要です。既定のページアクセスは `activeTab` の一時的な許可で、全サイトへのアクセスは希望する利用者が設定から許可する方式です。

## インストール・更新

1. `FastPageChat-0.10.2-windows-x64-Setup.exe` を実行し、補助アプリと同梱拡張機能を更新します。
2. Chromeの `chrome://extensions` でFast Page Chatを再読み込みします。初回導入ではデベロッパーモードを有効にし、`%LOCALAPPDATA%\FastPageChat\app\extension` を読み込みます。
3. 通常のWebページでツールバーの拡張機能ボタンを押し、参照本文を確認してから質問を送信します。

拡張機能を別フォルダーで管理している場合は、`fast-page-chat-0.10.2-extension.zip` で同じフォルダーの内容を更新して再読み込みしてください。履歴を残すため、通常の更新では拡張機能を削除しません。生成中の会話は停止してから更新します。

Chrome Web Storeには未公開で、拡張機能の手動読み込みが必要です。Windowsインストーラーは未署名です。配布元と `SHA256SUMS-0.10.2.txt` を確認してください。

0.10.1で修正した環境変数の重複と、更新時のWindows権限エラーへの対応も含みます。[以前の検証記録](https://github.com/Ringoacid/fast-page-chat/blob/main/docs/validation-0.10.1.md)と、新しいバージョンの確認結果は分けて管理します。`cleanInstallVerified` はfalseのままです。

Codexは利用者のアカウントで利用可能なモデル・制限が適用されます。OpenAI APIにはAPIキーと別途API利用料金が必要です。データの取り扱いは[プライバシーポリシー](https://ringoacid.github.io/fast-page-chat/privacy.html)、不具合の報告先は[GitHub Issues](https://github.com/Ringoacid/fast-page-chat/issues)を参照してください。認証情報や非公開のページ本文は投稿しないでください。
