# Chrome Web Store掲載原稿

公開前の原稿。Windowsヘルパーの配布・導入検証と公開URLの確定後に、実際の提供条件に合わせて最終確認する。

## 名前

Fast Page Chat

## 短い説明

いま開いているWebページを日本語で翻訳・要約・質問。本文と画像を確かめてからAIへ送信できます。

## 詳細説明

Fast Page Chatは、ページを開いたまま内容について質問できるサイドパネル拡張機能です。本文をコピーして別画面へ移動する手間を減らし、翻訳、要点の整理、文章の説明に使えます。

- 読み込み済みのページ本文、または選んだ文章を参照
- 画像ON時に本文の画像を参照し、プレビューで確認
- 翻訳・要約・説明の定型文を編集して送信
- チャット履歴の検索、名前変更、ピン留め、Markdownでの書き出し
- ライト／ダーク表示と、接続先・モデルの選択

利用にはWindows用接続ヘルパーと、利用可能なCodexアカウントまたはOpenAI APIの設定が必要です。OpenAI APIの使用には利用料金がかかります。接続先によって利用可能なモデルや利用制限が異なります。

本文の抽出はPC内で行います。質問を送信すると、参照本文、質問、会話の一部と、画像ON時の画像を、PC内のヘルパーを経由してOpenAIへ送信します。自動タイトル生成にもページ名と会話の一部を追加送信します。履歴はブラウザ内に保存します。外部画像の取得では画像配信元にも通信します。詳しくは公開プライバシーポリシーをご確認ください。

ページアクセスは通常、拡張機能ボタンを押したページへの一時的な許可です。全サイトへのアクセスと外部画像取得の許可は任意で、ブラウザ設定から管理できます。本文を完全に抽出できないサイトもあります。PDF、動画、iframe内部、まだ読み込まれていないコメントなどは対象外です。

本拡張機能はOpenAI、Googleの公式製品ではありません。AIの回答の正確性や、すべてのページ・画像への対応を保証するものではありません。

## 権限の説明

| 権限 | 利用目的 |
| --- | --- |
| activeTab | 利用者が拡張機能ボタンを押したページの本文・画像の取得。必要時の表示画像の切り出し。 |
| scripting | 許可されたページ内で本文・画像候補を読み取る処理の実行。 |
| sidePanel | ページを開いたままチャットする画面の表示。 |
| storage | 接続・表示設定や一時的な下書きなどの保存。 |
| nativeMessaging（ヘルパー版） | 同じWindows PCにインストールした接続ヘルパーの起動・接続・設定。 |
| http://127.0.0.1/* | 同じPCの接続サーバーへのアクセス。 |
| 任意のhttp/httpsホスト権限 | 許可されたサイトの自動取得と、外部画像の元データ取得。 |

最終申告は配布するmanifestの権限と照合する。未実装の権限用途は掲載しない。

## Privacy practices申告の準備

Webサイトのコンテンツ、ページ名・URL、質問・会話、画像、接続・認証設定を扱う。ページの種類に応じて個人情報や私的な通信を含むことがある。公開者がデータを受信しないことと、拡張機能が取得・保存・第三者送信しないことを混同しない。各項目は最新のダッシュボード定義と実際の対象データを照合して申告する。

公開者名はRingoacid、[ホームページ](https://ringoacid.github.io/fast-page-chat/)、[サポート](https://github.com/Ringoacid/fast-page-chat/issues)、[プライバシーポリシー](https://ringoacid.github.io/fast-page-chat/privacy.html)を指定する。URLは `docs/publication.json` でも管理する。申請前にログイン不要で閲覧できることを確認する。この原稿はストア公開済みであることを示さない。

## 素材

| 素材 | 仕様・構図 |
| --- | --- |
| 拡張機能アイコン | PNG 128×128。16、32、48pxも同じ意匠で作成し、manifestで指定。明暗両背景と小さい表示で確認。 |
| 小さいプロモーション画像 | 440×280。実際のブランド・用途を伝える。個人情報や第三者のロゴを含めない。 |
| スクリーンショット | 1280×800または640×400、最低1枚・最大5枚。実際の拡張機能UIを使う。翻訳、本文・画像確認、履歴を掲載候補とする。 |
| 任意の大きいプロモーション画像 | 1400×560。公開時に必要性を判断。 |

撮影には公開してよい人工ページと架空の会話を使用し、アカウント、キー、実際の閲覧履歴を含めない。スクリーンショットはUI変更後に撮り直す。2026-09-25に確認した[Chrome Web Storeの画像要件](https://developer.chrome.com/docs/webstore/images)と[ユーザーデータ要件](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)に基づく。申請前にも最新版を確認する。
