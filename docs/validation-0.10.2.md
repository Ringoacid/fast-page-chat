# 0.10.2の検証記録

対象: 0.10.2。記録開始日: 2026-09-25。Chrome 154のツールバー操作でページアクセスが付与されない問題への対応を検証します。修正後の自動チェックとVM動作を確認しています。未完了の項目は下表に残しています。

## 0.10.1で確認できた範囲と新たな問題

Windows 11 HomeのVMでは、0.10.1の補助アプリへの接続、利用者自身のCodexログイン、モデル一覧の表示まで確認しました。通常のページでツールバーからパネルは開きますが、ページを読む一時的な権限が付かず、本文を取得できませんでした。最初の実モデル回答には進んでいません。

0.10.1のインストール・更新と公開の証拠は[以前の検証記録](validation-0.10.1.md)に残しています。これらの成功を0.10.2の成功とは扱いません。

## 変更の範囲

サイドパネルの自動開閉を無効にし、通常の拡張機能ボタンのクリック処理でパネルを開きます。新しい会話を準備中なら、クリックしたタブの本文を再取得します。保存済みの会話、生成中の処理、初回案内の確認前は、その状態を維持します。閉じる操作はパネル右上の「×」です。要求する権限の範囲、データの送信先・保存先は変更しません。

VMで初回回答を確認した際に、自動タイトルだけがCodexの既定モデルを表す空文字を拒否する不具合も見つかりました。Codexの空文字だけを既定モデルとして許可し、APIのモデル指定と不正なIDの検証は維持します。
