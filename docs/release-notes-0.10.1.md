# Fast Page Chat 0.10.1 — GitHubベータ版

起動元の環境変数に `PATH` と `Path` が共存する場合、Windowsセットアップや補助アプリへの接続が重複キーのエラーで失敗する問題を修正しました。Windowsのユーザー・システム環境変数は変更しません。ページ本文・画像・会話の取り扱いは0.10.0と同じです。

既存のデータフォルダーがある更新・再インストールで、アクセス権の設定処理が不要なWindows権限を要求して失敗する問題も修正しました。データフォルダーを現在のWindowsユーザーとSYSTEMだけが利用できるようにする設定は維持します。

## インストール・更新

1. `FastPageChat-0.10.1-windows-x64-Setup.exe` を実行して、補助アプリをインストールまたは更新します。
2. 初回導入では、Chromeの `chrome://extensions` でデベロッパーモードを有効にし、`%LOCALAPPDATA%\FastPageChat\app\extension` を読み込みます。すでに同じ場所から読み込んでいる場合は、Chrome側の拡張機能を再読み込みします。
3. 通常のページで拡張機能を開き、初回案内から接続・ログインします。

別フォルダーで拡張機能を管理している場合は、`fast-page-chat-0.10.1-extension.zip` で同じフォルダーの内容を更新してから再読み込みしてください。通常の更新では拡張機能を削除しません。生成中の会話は停止してから更新してください。

Chrome Web Storeには未公開のため、拡張機能の手動読み込みが必要です。Windowsインストーラーは未署名です。配布元と `SHA256SUMS-0.10.1.txt` のチェックサムを確認してください。Windowsの設定や組織ポリシーによって実行できない場合があります。

- 単体テスト85件と、コンパイル済みWindowsランチャー・隔離Chromiumを使う検証14項目が成功しました。重複する環境変数はWin32の実際の環境ブロックで再現しています。モデルへの要求は行っていません。
- Windows 11 Home 25H2のVMでは、通常のエクスプローラー起動による0.10.0のインストール成功を確認しました。すべての通常PCで失敗する問題とは判断していません。
