Fast Page Chatは、Webページの本文と、必要に応じて画像を参照しながら、翻訳・要約・質問できる非公式の拡張機能です。Codex App ServerまたはOpenAI APIを利用します。

GitHubで配布するベータ版です。Chrome Web Storeには未公開です。現在の導入方法と検証状況をリポジトリのREADMEで確認してください。

必要な情報を確かめてから送信

ページの本文はPC内で抽出し、送信前に確認できます。質問の送信時にOpenAIへ渡します。画像は初期状態でOFF、履歴はブラウザ内に保存します。外部画像の取得には配信元への通信が発生します。

プライバシーポリシーを読む

利用に必要なもの

デスクトップ版Chrome、Windows用の接続ヘルパー、利用可能なCodexアカウントまたはOpenAI API設定が必要です。API利用には利用料金がかかります。対応モデルと利用制限はアカウントによって異なります。GitHub版の拡張機能はChromeの開発者向け機能から手動で読み込みます。
